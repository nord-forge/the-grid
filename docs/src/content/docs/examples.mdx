## Try it

- **Sort:** click a column heading. Shift-click another heading to add a sort column.
- **Filter:** use the search field for a quick filter, or hover over a column heading to reveal its filter button. Keyboard focus reveals it too.
- **Group:** choose **Group by team**, then expand and collapse the groups.
- **Select:** use the row checkboxes. The header checkbox selects all matching rows.
- **Edit text:** double-click a name or role, type a new value, and press Enter. Escape cancels.
- **Choose a team or status:** double-click a Team or Status cell to open its choices immediately. Selecting an option saves the choice. In **Settings**, the **Open dropdown on double-click** checkbox disables automatic opening if you prefer to focus the editor first.
- **Customize select icons:** open **Settings** and choose Chevron, Caret, or None, then open a Team or Status editor. Indicators appear only while editing.
- **Edit a budget:** double-click a Budget cell. The editor keeps the euro sign, right alignment, thousands separators, and two decimal places on entry. Type a non-negative amount with up to two decimal places. Enter or Tab saves it; Escape cancels. Sorting and filtering keep using numeric values.
- **Ranges:** drag across cells, or use Shift with the arrow keys. Copy uses the formatted cell values.
- **Paste and fill:** paste values into editable cells or drag the fill handle on a range. Team and Status accept their listed options; Budget accepts numbers and copied euro amounts. Invalid values are rejected without overwriting the original data.
- **Layout:** resize a column using its header edge. The name column stays pinned while you scroll horizontally.

Try [file uploads](/guides/uploads/#try-it) in their own focused example.

Changes live only in this example. **Reset** creates fresh rows and resets the grid. The [editing guide](/guides/editing/) explains how to persist writes to your API.

## How it is built

The example imports `Grid` from this repository's current source. It uses a local data source, typed columns, built-in select and currency editors, a status renderer, and the default stylesheet with a teal accent. The change counter records successful writes.

```tsx
<Grid<Person>
  data={data}
  columns={columns}
  defaultColumn={{ sortable: true, resizable: true }}
  rowSelection="multiple"
  interaction="cell"
  enableRanges
  enableFill
  stickyGroupRows
  headerFilterButton="always"
  ariaLabel="People example"
/>
```

Browse the [grid component](https://github.com/nord-forge/the-grid/blob/main/docs/src/components/GridDemo.tsx), [column definitions](https://github.com/nord-forge/the-grid/blob/main/docs/src/components/demoColumns.tsx), and [editors](https://github.com/nord-forge/the-grid/blob/main/docs/src/components/DemoEditors.tsx) on GitHub for the complete implementation.

## Select editor icons

Supply a custom glyph through the grid's `icons.select`. Built-in editors use it automatically; custom editors receive it through `CellEditorProps.icons`. It does not add an indicator to display cells.

```tsx
<Grid
  data={data}
  columns={columns}
  icons={{ select: <YourChevronIcon /> }}
/>
```

Set `select: false` to hide the indicator. The demo editor also accepts `cellEditorParams: { icon: <YourChevronIcon /> }` for a column-specific override.
